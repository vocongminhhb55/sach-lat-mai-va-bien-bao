# 📖 Sách Lật Tương Tác: Mai và Chuyến Phiêu Lưu Của Những Biển Báo

Dự án sách thiếu nhi điện tử tương tác 3D đa phương tiện, chuyển thể từ tác phẩm **"Mai và Chuyến Phiêu Lưu Của Những Biển Báo"** của tác giả **Kim Thanh Lê Huỳnh**.

---

## ✨ Tính Năng Nổi Bật

1. **Hiệu Ứng Lật Sách 3D Sống Động:**
   - Mô phỏng lật mở trang sách giấy chân thực với bóng đổ, độ cong và âm thanh sột soạt lật trang tự nhiên (sử dụng thư viện `page-flip` chạy độc lập Offline).
   - Tương thích tốt trên cả máy tính, máy tính bảng (iPad) và điện thoại thông minh.

2. **Tự Động Đọc Lời Kể Tiếng Việt (Read-Aloud):**
   - Tích hợp giọng đọc tiếng Việt truyền cảm, rõ ràng, phù hợp cho lứa tuổi thiếu nhi.
   - Hỗ trợ dừng/phát, đọc lại từng trang, tùy chỉnh bật/tắt âm thanh.

3. **Chữ Chạy Hiệu Ứng Karaoke (Word-by-word Highlight):**
   - Từng từ trong câu chuyện tự động bôi đậm và phát sáng theo thời gian thực ăn khớp chính xác với nhịp đọc.

4. **Ảnh Minh Họa Động & Khớp Với Lời Đọc (Audio-Visual Sync):**
   - Khi giọng đọc nhắc đến từ khóa (ví dụ: *"biển báo Nguy hiểm có trẻ em"*, *"Cấm quẹo trái"*, *"Ưu tiên ô tô"*, *"Tốc độ tối đa 40 km/h"*, *"mũ bảo hiểm"*):
     - Biển báo và đối tượng trên tranh minh họa bên trái sẽ **tự động phóng to, phát sáng hào quang rực rỡ, rung lắc hoặc chuyển động**.
   - Bé cũng có thể **chạm/click trực tiếp vào từng biển báo** trên tranh để nghe tên biển báo và âm thanh vui nhộn!

5. **Tự Động Lật Trang (Auto Turn Pages):**
   - Sau khi đọc xong hết câu chuyện ở trang hiện tại, hệ thống tạo một khoảng dừng tự nhiên cho bé ngắm tranh rồi **tự động lật sang trang tiếp theo**.

6. **Không Cần Cài Đặt - Chạy Mượt Cả Offline:**
   - 100% mã nguồn Web chuẩn (HTML5 / CSS3 / JavaScript thuần), không cần cài đặt Node.js hay server phức tạp. Bấm đúp vào `index.html` là đọc được ngay.

## 🚀 Hướng Dẫn Push Lên GitHub Bằng GitHub Desktop (Chỉ 2 Bước)

### Bước 1: Mở trên GitHub Desktop
1. Khởi động phần mềm **GitHub Desktop** trên máy tính của bạn.
2. Bấm vào menu **File** ➔ chọn **Add local repository...** (hoặc nhấn phím tắt `Ctrl + O`).
3. Bấm **Choose...** và điều hướng tới thư mục này:
   `c:\Users\Minh\Desktop\ThoTT\Sach Lat`
4. Bấm **Add repository**.

### Bước 2: Đẩy lên GitHub (Publish)
1. Trên thanh công cụ GitHub Desktop, bạn sẽ thấy nút xanh **"Publish repository"**. Bấm vào nút này.
2. Đặt tên repository (ví dụ: `sach-lat-mai-va-bien-bao`), bỏ tích chọn *"Keep this code private"* nếu muốn ai cũng xem được link.
3. Bấm **Publish repository** ➔ Quá trình upload sẽ hoàn tất trong vài giây!

## 🌐 Hướng Dẫn Bật Link Web Trực Tuyến (GitHub Pages)

Sau khi Publish repository thành công lên GitHub:
1. Mở trang repository của bạn trên [github.com](https://github.com).
2. Vào thẻ **Settings** (Cài đặt) ở thanh menu trên cùng.
3. Ở cột bên trái, bấm vào mục **Pages**.
4. Tại mục **Branch**, chọn nhánh **`main`** (hoặc `master`), thư mục giữ nguyên là `/ (root)`, rồi bấm nút **Save**.
5. Sau 1 phút, GitHub sẽ cấp cho bạn một đường link web chính thức có dạng:
   👉 **`https://vocongminhhb55.github.io/sach-lat-mai-va-bien-bao/`**
6. Bạn chỉ cần sao chép link này gửi cho phụ huynh, học sinh hoặc giáo viên là họ có thể mở đọc sách tương tác ngay lập tức!
